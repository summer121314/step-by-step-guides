第一篇 · 网站搭建

从零把网站发布到互联网：GitHub、Vercel 与 Google Search Console

适合不懂代码、不懂英文的新手。按照真实练习流程整理，包含踩坑解决方案。Google收录并非即时，也不保证排名。

准备材料
  • 一个可用的邮箱和 Google 账号
  • 网站源代码（至少含 index.html）
  • GitHub 及 Vercel 免费账户

1. 注册 GitHub

  1. 访问 github.com/signup。
  2. 填写邮箱、用户名、密码并完成人机验证。
  3. 如某个 Chrome 用户配置文件的验证码一直失败，可尝试无痕模式、清除 GitHub 网站数据、暂时禁用干扰扩展，或切换 Chrome 用户配置文件。

2. 创建仓库并上传文件

  1. 打开 github.com/new。
  2. 填写 Repository name；练习站可选 Public；创建仓库。
  3. 在仓库中选择 Add file → Upload files，把 ZIP 解压后的文件上传，不要上传 ZIP 本身。
  4. 点击 Commit changes 保存。确认 index.html 位于仓库根目录。

3. 使用 Vercel 上线

  1. 打开 vercel.com/new，用 GitHub 登录并授权仓库访问。
  2. 导入刚创建的仓库，Framework Preset 选 Other，Root Directory 用 ./。
  3. 点击 Deploy，等待状态显示 Ready。
  4. 在项目 Overview → Domains 找到真正的 vercel.app 网址，使用电脑和手机测试功能。

4. 添加 Google Search Console

  1. 打开 Google Search Console。
  2. 选择 URL prefix（网址前缀），填写完整的 https://你的网站.vercel.app/。
  3. 选择 HTML tag 验证，把专属 <meta name="google-site-verification" content="..." /> 放入首页 <head> 内。
  4. 在 GitHub 提交修改，等待 Vercel 自动部署为 Ready，再返回 Google 点击「確認」。
常见错误：「確認メタタグが見つかりませんでした」表示 Google 没在公开首页找到验证码。检查是否粘贴进 head、是否保存、Vercel 是否部署完成。

5. 制作并提交 Sitemap

在仓库根目录创建 sitemap.xml，用你自己的真实域名替换示例域名。注意 XML 声明前不能有空行。

<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url>
    <loc>https://your-site.vercel.app/</loc>
  </url>
</urlset>

把文件上传 GitHub，等部署成功后，打开 https://你的网站/sitemap.xml 测试。在 GSC「サイトマップ」中提交 sitemap.xml。

6. 三个真实排错案例

错误 A：XML declaration allowed only at the start of the document

原因是 <?xml 前有空行或字符。删掉第一行空白后重新提交。

错误 B：許可されていない URL（不允许的网址）

检查 <loc> 是否仍写着 YOUR-DOMAIN.com，必须换成自己网站的正确网址；GSC 旧的抓取报告可能不会立即更新。

错误 C：取得できませんでした（无法获取）

先在浏览器直接打开 Sitemap，确认不存在 404 或 XML 语法错误，再等待 Google 更新状态。

7. 请求 Google 收录

  1. 进入 GSC 顶部「URL 検査」，输入首页完整 URL。
  2. 如果显示「URL が Google に登録されていません」，点击「インデックス登録をリクエスト」。
  3. 显示请求已提交后，不必反复点击。Google 抓取与收录可能要数天至数周，而且不保证一定收录。
完成标准

网站能访问、功能正常、所有权验证成功、Sitemap可读取且网址正确、收录请求已提交。是否获得排名和收入要长期观察。
