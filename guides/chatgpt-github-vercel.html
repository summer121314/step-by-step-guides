第二篇 · AI 建站实操

不用自己上传代码：用 ChatGPT 完成 GitHub + Vercel 网站上线

这是一次真实操作复盘：用户描述网站需求，ChatGPT 编写网站并通过授权连接更新 GitHub，Vercel 自动部署。部分步骤仍需用户本人授权、创建仓库或手动点击部署。不同账号和产品版本提供的功能可能不同。

本篇要完成什么？

制作一个可分享多篇教程的网站，并实现：准备代码 → GitHub 保存 → Vercel 上线 → 获得公开网址 → 以后通过 ChatGPT 更新文章。

与第一篇区别：第一篇是手动上传文件的流程；本篇重点介绍如何让 ChatGPT 尽量代劳。

1. 向 ChatGPT 说明网站需求

你可以直接复制下面的需求发给 ChatGPT：

帮我做一个中文教程分享网站。首页显示教程卡片，
每篇教程有独立网址，方便分享。风格简洁，适配手机。
先写一篇教程，以后可以持续添加文章。
请帮我完成代码，并尽可能连接 GitHub 和 Vercel 发布。
所有需要我授权或确认的步骤请明确告诉我。

ChatGPT 可以设计网页、撰写教程、生成代码并协助修改；但是否能够直接操作你的账户，取决于已连接的应用和所授予的权限。

2. 在 ChatGPT 中连接 GitHub 和 Vercel

  1. 在 ChatGPT 的 Plugins（插件）中搜索 GitHub 和 Vercel（页面入口可能调整）。
  2. 按界面提示安装或连接插件，在跳转的官方页面登录自己的账号并授权。
  3. 回到对话，请 ChatGPT 检查是否能访问已有仓库或项目。“插件已安装”不等于“授权成功”。
  4. 不需要把账号密码、访问令牌贴进聊天。
实际遇到的情况

GitHub 连接可写入文件，Vercel 连接能列出已有项目，但自动新建 Vercel 项目时返回 403 Forbidden。这说明“可以读取”不一定意味着“可以创建项目”。遇到这种情况，可以改用 Vercel 网页手动导入，无须重做网站。

3. 创建 GitHub 仓库

先请 ChatGPT 尝试创建新仓库。如果当前连接不支持这个操作，自己打开 GitHub New repository，输入例如 step-by-step-guides，设为 Public，并创建空仓库。公开仓库意味着代码和文章对所有人可见，上传前检查是否含有个人信息或密钥。

完成后告诉 ChatGPT：“仓库建好了，请把刚才的网站文件上传到这个仓库。”

4. 让 ChatGPT 上传网站

授权与权限允许时，ChatGPT 可把 index.html、style.css、教程页面及 vercel.json 写进 GitHub，并返回提交结果。你只需要打开仓库确认文件确实出现。

本次实操中，首页与教程文件由 ChatGPT 写入 GitHub；每次提交后都保留了文件历史。以后新增文章也可以用同样方式完成。

5. 连接到 Vercel 并部署

  1. 打开 Vercel New Project。
  2. 在 Import Git Repository 中选择新仓库。如果看不到，点击 Adjust GitHub App Permissions。
  3. 在 GitHub 的 Vercel 应用授权中，将新仓库添加到可访问列表；保留原有项目的授权。
  4. 导入仓库，设置 Framework Preset = Other、Root Directory = ./，点击 Deploy。
  5. 出现 Congratulations! 后点击 Continue to Project，在 Domains 找到公开网址。
权限问题快速对照

403 Forbidden：当前连接可能无权访问该账户范围或执行创建操作，改由官网操作或检查连接授权。

Vercel 列表里只有旧仓库：不是代码丢了，通常是 GitHub App 还没有获准访问新仓库。调整权限后刷新 New Project 页面。

部署 Ready 但打不开文章：检查文章文件是否真的上传到对应路径，以及首页链接是否拼写正确。

6. 获取网址并检查

例如本次搭建的教程网站公开地址：step-by-step-guides-xi.vercel.app。打开首页，再点击第一篇教程，并在手机上试一次。注意：这个网址仅是本次案例，照做时要使用你自己的项目地址。

7. 让 ChatGPT 继续更新内容

以后可以直接说：

把今天的操作整理成一篇新手教程，
作为我的教程网站第三篇文章。
保留现有设计风格；加到首页卡片列表；
更新 GitHub 后检查 Vercel 是否重新部署成功。

如果 GitHub 与 Vercel 保持关联，向主分支提交代码通常会触发自动部署。请让 ChatGPT 报告真实的提交及部署状态，不要只凭“已处理”就认为已经上线。

8. 统计与搜索流量是下一阶段

Vercel Analytics 需要在项目中启用；对普通 HTML 网站通常还需要在页面 <head> 添加统计脚本：

<script defer src="/_vercel/insights/script.js"></script>

统计是从启用和正确加载脚本后开始的，不能自动追溯以前的访客。Google Search Console 的验证、Sitemap 与索引请求可以参考第一篇手动建站指南。收录请求不等于保证收录或排名。

最终核对清单
  • GitHub 能看到源代码和新文章
  • Vercel Production Deployment 为 Ready
  • 首页和文章链接在手机、电脑上都能打开
  • 未来修改 GitHub 后可以正常重新部署
  • 涉及账号授权、隐私或付费设置时由本人核对确认
