Use ChatGPT to Build and Deploy with GitHub and Vercel

This case study explains which steps ChatGPT can handle and which require your own account authorization.

Before you start

Connect GitHub and Vercel, publish a project, and solve common integration permission errors.

1. Describe the website you want

Give ChatGPT the audience, languages, layout, pages, mobile requirements and the features you expect. Ask for the complete deployable source and a testing checklist.

2. Connect GitHub and Vercel

Open the ChatGPT Plugins directory, find GitHub and Vercel, and authorize them through their official sign-in flows. A connected plugin may have read access without project-creation access.

3. Create an empty repository

If the connection cannot create a repository, open github.com/new yourself. Avoid uploading secrets to a public project.

4. Ask ChatGPT to upload files

Request that it write all page, script and configuration files to the new repository. Check the actual commits and folder paths before deploying.

5. Import into Vercel

In Vercel's New Project screen import the new repository. If it is missing, use Adjust GitHub App Permissions. Check framework, root directory, build and output settings.

6. Diagnose deployment issues

A 403 response usually indicates permissions or account scope. A missing page often points to a wrong file path. Check deployment logs and ensure Production is READY.

7. Update your site later

Ask ChatGPT to add a new article, link it on the homepage, update the sitemap and verify deployment. GitHub commits normally trigger a new Vercel build.

8. Analytics and Google indexing

Enable Vercel Web Analytics and its script if required. Verify the domain in Search Console, submit a sitemap, and monitor performance. Indexing is not immediate or guaranteed.
