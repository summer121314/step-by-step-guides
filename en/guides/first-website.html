Build Your First Website: GitHub, Vercel and Google Search

This walkthrough shows the practical steps to publish a static website and help Google discover it.

Before you start

A practical beginner's guide from repository creation to deployment and Search Console indexing.

1. Plan a small, useful site

Start with a simple HTML/CSS site. Decide what problem it solves, which pages it needs, and whether it works on mobile.

2. Create a GitHub repository

Open github.com/new, name the repository, choose visibility and create it. Upload index.html and other assets with the correct folder structure. Never upload passwords or API keys.

3. Deploy with Vercel

Open vercel.com/new, import the repository, select the correct framework and root directory, then click Deploy. If the repository is missing, adjust GitHub App permissions. Wait for READY, then open the production domain.

4. Test before sharing

Check homepage, links and mobile layout. Confirm static asset URLs are correct and the browser console does not show errors.

5. Connect Google Search Console

Choose a URL-prefix property, paste the exact https URL, select HTML tag verification and add Google's meta tag inside the homepage head. Redeploy and click Verify.

6. Add sitemap.xml and robots.txt

Create a sitemap listing real public page URLs. Place both sitemap.xml and robots.txt at the project root or public output root, then submit sitemap.xml in Search Console.

7. Request indexing

Use URL Inspection to request indexing for important pages. A successful request does not mean indexing is guaranteed. Daily quota errors can be retried another day.

8. Troubleshooting and next steps

If a sitemap fails, check that the URL opens, XML starts correctly and no placeholder domains remain. Track actual impressions and clicks in Search Console over time.
