実践ガイド

ChatGPTでサイト制作とGitHub・Vercel公開を進める方法

ChatGPTに任せられる作業と、自分で認証・確認する必要がある作業を実例から整理します。

始める前に

ChatGPTの連携機能、GitHubへのコード保存、Vercel自動デプロイと権限エラーの対処。

1. 作りたいサイトを具体的に伝える

対象読者、対応言語、ページ構成、スマホ対応、必要な機能をChatGPTに説明します。デプロイできる完全なコードとテスト項目も依頼しましょう。

2. GitHubとVercelを連携

ChatGPTのPluginsからGitHubとVercelを探し、各サービスの公式認証画面で許可します。接続済みでも作成権限があるとは限りません。

3. 空のリポジトリを作る

連携から作成できない場合、github.com/new で手動作成します。公開リポジトリに機密情報を入れないことが重要です。

4. コードをアップロードしてもらう

すべてのHTML、CSS、JavaScript、設定ファイルをGitHubに書き込むよう依頼します。実際のコミットとディレクトリ構成を確認してください。

5. Vercelで取り込む

New Projectで対象リポジトリを選びます。見つからないときはAdjust GitHub App Permissionsを確認し、フレームワーク、ルート、ビルド設定を選びます。

6. デプロイエラーを解決

403は認証範囲や権限が原因の可能性があります。ページが見つからない場合はファイルパスを確認。ログを見てProductionがREADYになるまで待ちます。

7. 後からページを増やす

新記事の作成、トップへのリンク追加、サイトマップ更新、デプロイ確認までセットで依頼すると管理が楽になります。

8. アクセス解析と検索登録

必要に応じてVercel Analyticsを有効にし、Search Consoleの所有権確認とサイトマップ送信を行います。検索結果への掲載は保証されません。
